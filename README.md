# Academic Performance Tracking

Веб-приложение для учета успеваемости студентов, автоматического расчета среднего балла и отображения результатов в личном кабинете.

> Проект разрабатывается поэтапно. На первом этапе подготовлен каркас Flask-приложения.

## Технологии

- Python 3.12+
- Flask — веб-фреймворк
- Flask-SQLAlchemy / SQLAlchemy — работа с базой данных
- SQLite — локальная база данных на этапе разработки
- Jinja2, HTML, CSS — интерфейс

## Структура

```text
academic_performance_tracking/
├── app/
│   ├── models/          # Модели базы данных (следующие этапы)
│   ├── routes/          # Маршруты приложения
│   ├── services/        # Бизнес-логика и расчеты
│   ├── static/
│   │   ├── css/
│   │   └── js/
│   ├── templates/       # HTML-шаблоны
│   ├── __init__.py      # Фабрика create_app()
│   └── extensions.py    # Инициализация расширений Flask
├── instance/            # Локальная БД (создается автоматически)
├── tests/               # Автоматические тесты (будут добавлены далее)
├── config.py
├── run.py
├── requirements.txt
└── README.md
```

## Запуск на Windows

```powershell
py -3.12 -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install -r requirements.txt
python run.py
```

Откройте в браузере: http://127.0.0.1:5000

Проверка состояния приложения: http://127.0.0.1:5000/health

## Запуск на macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

## Примечание по безопасности

Значение `SECRET_KEY` по умолчанию предназначено только для локальной разработки. Перед развертыванием необходимо задать собственный случайный секрет через переменную окружения `SECRET_KEY`. Файл `.env` не следует добавлять в Git.
